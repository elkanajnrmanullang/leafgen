LeafGenn

Sistem Otomatisasi Desain Leaflet Promosi

📝 Latar Belakang & Alur Kerja Final

Permasalahan Utama

Proses pembuatan leaflet promosi saat ini menghadapi beberapa tantangan signifikan yang menyebabkan inefisiensi. Proses manual oleh 9 staf desain untuk berbagai daerah memakan waktu minimal 8 jam per leaflet, dengan tambahan 4 jam untuk revisi akibat *human error* (salah ketik harga, salah gambar, dll.). Kolaborasi menjadi sulit ketika staf absen, karena mengharuskan penggunaan laptop fisik milik staf tersebut. Tujuan utama sistem ini adalah memangkas total waktu kerja tersebut hingga kurang dari 1 jam, atau mencapai efisiensi lebih dari 90%.

Alur Kerja Sistem

  • Buat Leaflet dari CSV: Staf mengunggah file CSV. Sistem membaca data produk dengan mencocokkan Kode PLU Unit ke Bank Gambar, lalu menampilkan pilihan daerah dari CSV. Setelah daerah dipilih, sistem secara otomatis menghasilkan pratinjau layout grid cerdas yang dapat diedit di editor visual "Canva-like" sebelum diunduh sebagai PNG dan disimpan ke History.
  • Buat Leaflet dari Template: Staf memilih desain latar dari menu Template Desain. Sistem kemudian menampilkan galeri layout yang sudah ada dari History. Staf memilih salah satu layout untuk digabungkan dengan latar baru, lalu dapat melakukan penyesuaian akhir di editor visual. Hasilnya juga disimpan ke History dengan kode unik.
  • Manajemen Data: Staf dapat menambah produk baru ke Bank Gambar. Manajer (Admin) dapat mengelola akun pengguna, termasuk menambah pengguna baru (password dikirim via email) dan menonaktifkan akun (bukan menghapus) untuk menjaga integritas data history.

🎯 Informasi Inti & Batasan Proyek

Tujuan Kuantitatif

Mengurangi waktu pengerjaan leaflet dari 8+ jam menjadi kurang dari 1 jam, mencapai peningkatan efisiensi lebih dari 90%.

Proyek ini akan mencakup semua fitur yang telah didiskusikan, termasuk editor visual "Canva-like", dua alur kerja, dan manajemen akun tingkat lanjut.

Komitmen Waktu

🚀 Tumpukan Teknologi (Tech Stack)

  • Backend: Laravel

    - Membangun REST API sebagai "otak" dari seluruh logika aplikasi.

  • Frontend: React (Vite + TypeScript)

    - Membangun antarmuka pengguna yang interaktif dan modern.

  • Database: PostgreSQL

    - Menyimpan semua data secara persisten dan andal.

  • Styling: Tailwind CSS

    - Kerangka kerja CSS untuk desain yang cepat dan konsisten.

  • Server & Deployment: VPS Ubuntu, Nginx, Supervisor

    - Infrastruktur untuk menjalankan aplikasi secara online.

💾 Desain Database

1. Tabel `users`

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
name VARCHAR Nama lengkap pengguna
email VARCHAR Alamat email (unik)
username VARCHAR Username (unik)
password VARCHAR Password (hashed)
role ENUM('manager', 'staff') Peran pengguna
status ENUM('active', 'inactive') Status akun
password_changed_at TIMESTAMP Waktu password diubah
created_at, updated_at TIMESTAMP Otomatis oleh Laravel

2. Tabel `products` (Bank Gambar)

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
plu_code VARCHAR Kode PLU Unit (unik)
name VARCHAR Nama produk
image_path VARCHAR Lokasi file gambar
created_at, updated_at TIMESTAMP Otomatis oleh Laravel

3. Tabel `background_templates`

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
title VARCHAR Judul template
image_path VARCHAR Lokasi file gambar latar
user_id BIGINT Foreign Key ke `users.id`
created_at, updated_at TIMESTAMP Otomatis oleh Laravel

4. Tabel `leaflets` (History)

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
code VARCHAR Kode unik (LFG-XXX / TDLG-XXX)
region VARCHAR Wilayah leaflet
promotion_start_date DATE Tanggal mulai promosi
promotion_end_date DATE Tanggal selesai promosi
final_image_path VARCHAR Lokasi file PNG final
user_id BIGINT Foreign Key ke `users.id`
created_at, updated_at TIMESTAMP Otomatis oleh Laravel

5. Tabel `leaflet_items`

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
leaflet_id BIGINT Foreign Key ke `leaflets.id`
product_id BIGINT Foreign Key ke `products.id`
display_price DECIMAL Harga promosi
strikethrough_price DECIMAL Harga coret (opsional)
position_x INTEGER Koordinat posisi X
position_y INTEGER Koordinat posisi Y
custom_styles JSON Menyimpan data kustomisasi (font, dll)
