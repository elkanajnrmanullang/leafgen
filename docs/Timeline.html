LeafGenn

Sistem Otomatisasi Desain Leaflet Promosi

📝 Latar Belakang & Alur Kerja Final

Permasalahan Utama

Proses pembuatan leaflet promosi saat ini memakan waktu minimal 8 jam per leaflet, dengan tambahan 4 jam untuk revisi akibat *human error*. Kolaborasi menjadi sulit ketika staf absen, karena mengharuskan penggunaan laptop fisik milik staf tersebut. Tujuan utama sistem ini adalah memangkas total waktu kerja tersebut hingga kurang dari 1 jam, atau mencapai efisiensi lebih dari 90%.

Alur Kerja Sistem

  • Buat Leaflet dari CSV: Staf mengunggah file CSV. Sistem menampilkan pratinjau layout awal sesuai urutan data. Di dalam editor visual, staf dapat menekan tombol "Grid Cerdas" untuk menyusun ulang produk secara otomatis berdasarkan pola historis dari leaflet sebelumnya. Staf tetap memiliki kontrol penuh untuk penyesuaian akhir sebelum mengunduh sebagai PNG.
  • Buat Leaflet dari Template: Staf memilih desain latar dari menu Template Desain. Sistem kemudian menampilkan galeri layout dari History untuk digabungkan dengan latar baru, lalu dapat melakukan penyesuaian akhir di editor visual.
  • Pembelajaran Mandiri (Self-Learning): Setiap leaflet yang disimpan ke History menjadi data baru bagi model machine learning, membuatnya semakin pintar dalam memberikan rekomendasi tata letak di masa depan.
  • Manajemen Data: Staf dapat menambah produk ke Bank Gambar. Manajer (Admin) dapat mengelola akun pengguna, termasuk menambah pengguna baru dan menonaktifkan akun untuk menjaga integritas data history.

🧠 Konsep Machine Learning: Grid Cerdas

Fitur "Grid Cerdas" merupakan inovasi utama dalam proyek ini yang membedakannya dari sistem otomatisasi biasa. Fitur ini dirancang untuk meniru intuisi desainer dalam mengelompokkan produk-produk yang relevan.

  • Model yang Digunakan: Sistem menggunakan teknik machine learning Association Rule Mining dengan algoritma Apriori. Tujuannya adalah untuk menemukan "aturan asosiasi" atau pola produk yang sering muncul bersamaan dalam satu leaflet.
  • Sumber Dataset: Dataset untuk model ini tidak diinput manual, melainkan dibangun secara otomatis dari seluruh data di menu History. Setiap leaflet yang disimpan dianggap sebagai satu "transaksi" data.
  • Mekanisme "Cold Start": Untuk menjamin kualitas rekomendasi, fitur "Grid Cerdas" dirancang untuk mengatasi cold start problem. Tombol fitur ini baru akan muncul dan aktif setelah sistem memiliki minimal 5 data leaflet di dalam History untuk dipelajari.

🎯 Informasi Inti & Batasan Proyek

Tujuan Kuantitatif

Mengurangi waktu pengerjaan leaflet dari 8+ jam menjadi kurang dari 1 jam, mencapai peningkatan efisiensi lebih dari 90%.

Ruang Lingkup Penuh

Proyek ini akan mencakup semua fitur yang telah didiskusikan, termasuk fitur "Grid Cerdas" berbasis *machine learning*.

Deadline Mutlak

Aplikasi harus selesai, diuji, dan di-deploy di server paling lambat pada 17 November 2025.

Komitmen Waktu

Timeline ini didasarkan pada komitmen pengerjaan 8 jam per hari, 7 hari per minggu.

🚀 Tumpukan Teknologi (Tech Stack)

  • Backend: Laravel

    - Membangun REST API dan logika *machine learning*.

  • Frontend: React (Vite + TypeScript)

    - Membangun antarmuka pengguna yang interaktif.

  • Database: PostgreSQL

    - Menyimpan semua data, termasuk dataset untuk ML.

  • Styling: Tailwind CSS

    - Kerangka kerja CSS untuk desain yang cepat.

  • Server & Deployment: VPS Ubuntu, Nginx, Supervisor

    - Infrastruktur untuk menjalankan aplikasi secara online.
