LeafGenn

Sistem Otomatisasi Desain Leaflet Promosi

📝 Latar Belakang & Alur Kerja Final

Permasalahan Utama

Proses pembuatan leaflet promosi saat ini memakan waktu minimal 8 jam per leaflet, dengan tambahan 4 jam untuk revisi akibat *human error*. Kolaborasi menjadi sulit ketika staf absen, karena mengharuskan penggunaan laptop fisik milik staf tersebut. Tujuan utama sistem ini adalah memangkas total waktu kerja tersebut hingga kurang dari 1 jam, atau mencapai efisiensi lebih dari 90%.

Alur Kerja Sistem

  • Buat Leaflet dari CSV (Alur Utama):
    • Staff mengunggah file .csv atau .xlsx.
    • Sistem menampilkan dropdown daerah dari file, Staff memilih daerah dan input periode tanggal.
    • Sistem memfilter data, mencocokkan Kode PLU dengan Bank Gambar, dan menampilkan pratinjau layout grid otomatis (ukuran grid adaptif).
    • Masuk ke Editor Visual: Staff dapat menggeser grid, mengedit teks, dan menggunakan tombol "Grid Cerdas" (jika aktif) untuk optimasi layout berdasarkan history.
    • Staff mengunduh hasil final sebagai PNG. Hasil otomatis tersimpan ke History.
  • Buat Leaflet dari Template:
    • Staff memilih desain latar dari menu Template Desain.
    • Sistem menampilkan galeri layout grid dari History.
    • Staff memilih layout grid, sistem menggabungkan keduanya di Editor Visual untuk penyesuaian akhir sebelum diunduh (PNG) dan disimpan ke History.
  • Pembelajaran Mandiri (Self-Learning): Setiap leaflet yang disimpan ke History menjadi data latih baru bagi model machine learning ("Grid Cerdas"), membuatnya semakin akurat seiring waktu.
  • Manajemen Data:
    • Staff dapat menambah/melihat produk di Bank Gambar (Kode PLU, Nama, Deskripsi, Gambar).
    • Manager (Admin) dapat mengelola akun pengguna di menu Manajemen Akun: menambah pengguna baru (password dikirim ke email) dan menonaktifkan akun staf yang tidak aktif (data history tetap ada, tapi user tidak bisa login).
  • Keamanan Tambahan: Password pengguna akan kedaluwarsa setiap 1 bulan dan wajib diganti.

🧠 Konsep Machine Learning: Grid Cerdas

Fitur "Grid Cerdas" merupakan fitur pendukung opsional di dalam editor visual, dirancang untuk meniru intuisi desainer dalam mengelompokkan produk-produk yang relevan berdasarkan data historis.

  • Model yang Digunakan: Sistem menggunakan teknik machine learning Association Rule Mining dengan algoritma Apriori. Tujuannya adalah untuk menemukan "aturan asosiasi" (pola produk X sering muncul bersama produk Y) dari data history.
  • Sumber Dataset: Dataset dibangun secara otomatis dari seluruh data di menu History. Setiap leaflet (`leaflets`) beserta item-item di dalamnya (`leaflet_items`) dianggap sebagai satu "transaksi" data.
  • Mekanisme "Cold Start": Untuk menjamin kualitas rekomendasi, tombol fitur "Grid Cerdas" di editor visual baru akan muncul dan aktif setelah sistem memiliki minimal 5 data leaflet di dalam History.
  • Fungsi: Saat tombol diklik, sistem menganalisis data History, menemukan asosiasi produk, dan menyusun ulang layout grid di editor untuk menempatkan produk-produk berasosiasi kuat agar saling berdekatan.

🎯 Informasi Inti & Batasan Proyek

Tujuan Kuantitatif

Mengurangi waktu pengerjaan leaflet dari 8-12 jam menjadi kurang dari 1 jam, mencapai peningkatan efisiensi lebih dari 90%.

Ruang Lingkup Penuh

Proyek ini mencakup semua fitur yang telah didiskusikan, termasuk alur CSV, alur Template, editor visual, fitur "Grid Cerdas", History, Bank Gambar, Manajemen Akun, RBAC, dan fitur keamanan Ganti Password Wajib & Password Bulanan.

Deadline Mutlak

Aplikasi harus selesai, diuji, dan di-deploy di server paling lambat pada 17 November 2025.

Komitmen Waktu

Timeline ini didasarkan pada komitmen pengerjaan 8 jam per hari, 7 hari per minggu.

🚀 Tumpukan Teknologi (Tech Stack)

  • Backend: Laravel

    - Membangun antarmuka pengguna yang interaktif.

  • Database: PostgreSQL

    - Menyimpan semua data, termasuk dataset untuk ML.

  • Styling: Tailwind CSS

    - Kerangka kerja CSS untuk desain yang cepat.

  • Server & Deployment: VPS Ubuntu, Nginx, Supervisor

    - Infrastruktur untuk menjalankan aplikasi secara online.

💾 Desain Database

1. Tabel `users`

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
name VARCHAR Nama lengkap pengguna
email VARCHAR Alamat email (unik)
username VARCHAR Username (unik)
password VARCHAR Password (hashed)
role ENUM('manager','staff') Peran pengguna
status ENUM('active','inactive') Status akun
password_changed_at TIMESTAMP Waktu password terakhir diubah
created_at, updated_at TIMESTAMP Otomatis oleh Laravel

2. Tabel `products` (Bank Gambar)

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
plu_code VARCHAR Kode PLU Unit (unik)
name VARCHAR Nama produk
description TEXT Deskripsi produk (opsional)
image_path VARCHAR Lokasi file gambar
created_at, updated_at TIMESTAMP Otomatis oleh Laravel

3. Tabel `background_templates`

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
title VARCHAR Judul template
image_path VARCHAR Lokasi file gambar latar
user_id BIGINT Foreign Key ke `users.id` (pembuat)
created_at, updated_at TIMESTAMP Otomatis oleh Laravel

4. Tabel `leaflets` (History)

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
code VARCHAR Kode unik (misal: LFG-YYYYMMDD-XXX)
region VARCHAR Wilayah leaflet
promotion_start_date DATE Tanggal mulai promosi
promotion_end_date DATE Tanggal selesai promosi
final_image_path VARCHAR Lokasi file PNG final
user_id BIGINT Foreign Key ke `users.id` (pembuat)
created_at, updated_at TIMESTAMP Otomatis oleh Laravel

5. Tabel `leaflet_items`

Nama Kolom Tipe Data Keterangan
id BIGINT Primary Key
leaflet_id BIGINT Foreign Key ke `leaflets.id`
product_id BIGINT Foreign Key ke `products.id`
display_price DECIMAL Harga promosi
strikethrough_price DECIMAL Harga coret (opsional)
position_x INTEGER Koordinat posisi X (setelah diedit)
position_y INTEGER Koordinat posisi Y (setelah diedit)
custom_styles JSON Menyimpan data kustomisasi (font, warna, dll)
